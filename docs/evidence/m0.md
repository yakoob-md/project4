## Open acceptance check

The first live attempt, `7f57cfc3-20a5-4f89-8c1b-25be4c2001f6`, reached CrewAI and received Groq HTTP 404 after the SDK stripped the model ID prefix. Selecting its native OpenAI-compatible provider explicitly preserved the full ID and the rerun succeeded.

Langfuse project credentials were unavailable. The correlated trace was verified in Jaeger. To close the Langfuse gate, provide `LANGFUSE_HOST`, `LANGFUSE_PUBLIC_KEY`, `LANGFUSE_SECRET_KEY`, and `LANGFUSE_PROJECT_ID` in the shell and run the following command.
